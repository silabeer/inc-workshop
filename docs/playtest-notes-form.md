# Форма заметок наблюдателя

Распечатайте: первая страница — шапка и итоги, дальше по строке на шаг (сводная таблица) или по
карточке на шаг для подробных заметок. Цифровой вариант — поле «Заметка ведущего к шагу» на пульте:
заметки оттуда попадают в Markdown-отчёт («Скопировать итоги») и в «Аналитику по архиву».
