# inc-workshop — интерактивный воркшоп по боевым инцидентам

Тренажёр инцидент-респонса для живых воркшопов. Два режима на одном контенте:

## Холл-режим (`hall.html`) — для зала

Одна команда, пять ролей (Командир инцидента, Скаут наблюдаемости, Инженер платформы,
Доменный специалист, Связной). Кейс — цепочка решений: проектор показывает ситуацию,
диаграмму архитектуры и варианты; шаг ведёт назначенная роль, ведущий жмёт кнопки.
После выбора — последствия, очки, напряжение. Финал — разбор с метриками
(очки, ловушки, напряжение).

**Запуск:** открыть `hall.html` двойным кликом. Сервер не нужен.

Управление: `1–4` — выбор, `Enter`/`→` — дальше, `R` — в лобби.

Кейсы: «Фантомная сеть и шторм повторов», «Просроченный сертификат».

## War-room (`war-room.html` + `server.js`) — продвинутый режим для группы за столом

Реальное время, пять станций с ролями и асимметричной информацией, ключи улик,
автопилот инцидента, экономика (потери ₽/мин, паника), архив игр.

**Запуск:**

```bash
node server.js
# открыть в браузерах: #projector (экран зала), #gm (ведущий), #play (станции)
```

## Тесты

```bash
node --test --test-force-exit
```

## Структура

- `hall-engine.js` — движок холл-режима (валидация сценариев, ходы)
- `engine.js`, `server.js` — движок и сервер war-room
- `scenarios/hall-*.js` — кейсы холл-режима (графы решений + роли + диаграммы)
- `scenarios/phantom-network.js`, `scenarios/expired-cert.js` — контент-паки war-room
- `test/` — тесты обоих режимов
- `docs/superpowers/` — спеки и планы
