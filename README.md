# inc-workshop — тренажёр инцидент-респонса для живых воркшопов

Команда дежурных разбирает боевой инцидент: ищет причину по данным, обходит ловушки
(откат «виноватого» релиза, раздувание пула, WAF против «DDoS»), держит коммуникацию
с бизнесом и закрывает инцидент по критерию, а не по вспышке зелёного графика.

Два режима на одном контенте:

| | Холл-режим | War-room |
| --- | --- | --- |
| Для кого | Зал на 20–200 человек, одна команда | Группа из 5–9 человек за столом |
| Механика | Пошаговые решения, роль ведёт шаг | Реальное время, асимметричная информация |
| Экраны | Один проектор | Проектор + пульт ведущего + телефоны игроков |
| Длительность | 25–40 минут | 12–22 минуты игры, слот 35–60 минут |
| Сервер | Не нужен: `hall.html` двойным кликом | `node server.js` в одной Wi-Fi с игроками |

## Быстрый старт

Нужен Node.js 18+. Зависимостей нет, `npm install` не требуется.

```bash
# Холл-режим без сервера
open hall.html          # macOS; в Windows/Linux — открыть файл в браузере

# Оба режима через сервер (обязательно для war-room с телефонами)
npm start               # = node server.js, порт 8085
```

Сервер печатает адреса:

- `http://localhost:8085/hall.html` — холл-режим;
- `http://localhost:8085/#projector` — war-room, экран зала;
- `http://localhost:8085/#gm` — пульт ведущего;
- `http://<ip-ноутбука>:8085/#play` — терминалы игроков (телефоны в той же Wi-Fi).

### Docker

```bash
docker build -t inc-workshop .
docker run -d -p 8085:8085 -v inc-workshop-data:/app/data inc-workshop
```

Состояние игры и архив сыгранных партий лежат в томе `/app/data`.
Проверка живости: `GET /healthz`.

Переменные окружения: `PORT` (8085), `HOST` (0.0.0.0), `DATA_DIR` (каталог проекта).

## Кейсы

| Кейс | Холл | War-room | О чём |
| --- | --- | --- | --- |
| Просроченный сертификат | 8 шагов, до 14 очков | 12 минут, учебный режим с подсказками | Истёкший TLS на edge, а все смотрят на вчерашний релиз. Для первого знакомства |
| Фантомная сеть и шторм повторов | 10 шагов, до 19 очков | 22 минуты | Эквайер молчит без FIN/RST, вызовы без таймаутов, мобильный клиент добивает ретраями |

## Разработка

```bash
npm test                # = node --test; CI гоняет Node 18 и 22
```

```
hall.html               холл-режим: UI, работает по file://
hall-engine.js          движок холла: валидация кейса, ходы, итог (чистые функции)
war-room.html           war-room: проектор, пульт, терминалы игроков, исполнитель автопилота
engine.js               движок war-room: экономика, паника, автопилот (чистые функции)
server.js               HTTP + SSE, хранение состояния, архив игр
scenarios/hall-*.js     холл-кейсы
scenarios/*.js          war-room-паки
test/                   node:test, без фреймворков
```

Правила для разработчиков и агентов — в [`CLAUDE.md`](CLAUDE.md).
